# 识谱流程前后对比评测（2026-10-18）

本目录是一次**单次**实测的全部证据：测试曲目、页图、两组流程的配置与提示词、原始输出、运行日志、参考数据、评分程序输出和播放验证。所有数字都可以按文末“复现”一节重新计算。

结论先行（详细数据见下文）：

- **准确度**：优化流程（识读 + 独立复核）比基线（单一识读者）略好。音高+节奏（POD）召回率 99.5% → 99.9%，精确率 98.2% → 99.0%；完全正确小节 37/48 → 39/48。差异只有几个音，而且只测了一次，**不能据此断言有统计意义的提升**。

- **“5–8 分钟、Token 减少 80–90%、准确度不变”整体仍是未证实的假设**。本次实测是约 11 分钟、Token 增加、准确度小幅提高。
- **辅助工具在本曲上价值很低**：程序草稿没有一个小节的时值与音头一致（0/48）；重复小节候选 0 个（参考数据中第 2=35、3=36 小节音高节奏完全相同，均未检出）；复核阶段自动疑点大部分是误报。识读者实际上逐小节重写了全部内容。

## 3. 评分方法（`scripts/omr-benchmark-score.mjs`）

- **评分单元**：(小节, 手)，共 48 × 2 = 96 个单元。音符按起拍所在小节归属。连音线在参考和识读结果中都已合并为一个音。
- **对齐**：小节号直接对应，因为两组输出和参考都是 48 小节，且没有反复记号展开问题。超出参考范围的识读音为 0。
- **匹配层级**（同一单元内的多重集交集，一个参考音最多匹配一个识读音）：
  - P：音高（MIDI 音高）相同；
  - PO：音高相同且起拍相同（以四分音符为 1 拍，精确到 1e-3）；
  - POD：音高、起拍、时值都相同，即“音高与节奏同时正确”。
- **计数与比率**：
  - `matched` = 交集大小；
  - 漏音 = 参考音数 − matched；多音 = 识读音数 − matched；
  - 召回率 = matched / 参考音数（分母：右手 529、左手 353、合计 882）；
  - 精确率 = matched / 识读音数（分母为各流程该手的识读音数）。
- **起拍对时时值正确** = POD matched / PO matched，用来单独看节奏中的时值部分。
- **完全正确单元**：POD matched = 参考音数 = 识读音数。**完全正确小节**：左右两个单元都完全正确。
- **手别错误**：音放到另一只手时，记一个漏音加一个多音。另报“忽略手别的 PO”供诊断。
- 不评音名拼写（例如 G♯ 与 A♭），因为 MIDI 不记录拼写。

### 4.3 逐音错误（`results/error-details.txt`，由 `error-details.mjs` 生成）

- **主要误差来源是格式限制，不是读错**：两个声部共用一个符头时，`.bars` 格式要求两个声部各写一次，参考 MIDI 只保留一个音。这种情况计为多音。
  - 基线 16 个 POD 多音中有 11 个属于此类；
  - 优化流程复核后 9 个中有 7 个属于此类；
  - 两组都受影响，比较仍然公平，但绝对精确率因此被压低。
- **基线的真实读错**：
  - 第 14 小节左手 A2 读成 A♭2；
  - 第 17 小节左手 F♯2 读成 F2；
  - 第 22 小节右手 D4 读成 C♯4；
  - 第 17 小节右手 D4 时值错；
  - 第 46 小节左手多一个 G3。
- **优化流程复核后的真实读错**：第 17 小节右手 D4 时值错（1 拍读成 0.5 拍）；第 46 小节左手多一个 G3。
- **复核的实际作用**：第 1 页复核者修正了第 3 小节漏标的延音线（POD 多音 11 → 9），其余两页没有改动音符。
  - 第 2 页：无修改，9 个疑点全部是误报；
  - 第 3 页：1 处声部重新划分，不影响音符；
  - 第 1 页：1 处修改，6 个疑点是误报。

## 8. 调度修复（与本评测相关的部分）

见提交 `423cd15` 和 `tests/recognition-scheduling.test.mjs`（6 个测试，其中 4 个在旧代码上失败）：

## 9. 参考数据与评测的限制

- 参考 MIDI 与 PDF 出自同一 LilyPond 源，但没有经过人工逐音核对。
- 两声部共用符头时，MIDI 只保留一个音，因此正确的双声部写法会被计为多音。
- MIDI 不记录拼写，所以只评音高。
- **只有一首曲目、每组只运行一次，无法给出方差。** 两组差几个音，属于单次测量可能的波动范围。
- 优化流程中途遇到限额暂停，靠同一上下文续跑完成。这与一次不中断的运行不完全等价。
- 曲目知名，无法排除模型凭记忆补写（两组同样面临这一风险）。
