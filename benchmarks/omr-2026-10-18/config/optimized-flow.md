# 优化后流程（识谱辅助证据 + 分页独立识读 + 独立复核）

识谱辅助工具冻结于提交 `bc6dc13`（`scripts/omr-assist.py` sha256 前缀 `1c2fbff6d8fb1714`），本流程运行期间不修改。
所有识读/复核子任务与基线相同：同一会话模型（子任务继承主会话模型）、思考强度 `high`、全新上下文、不读取任何先前结果。

| 阶段 | 内容 | 并发 |
|---|---|---|
| 0 预处理 | `omr-assist.py detect`（`--key -4 --time 3/2`）→ `repeats` → `tasks --scale 2`；只读页图 | 本机 |
| 1 识读 | 每页一个识读者：该页整页图 + 各行放大裁图 + 程序草稿。草稿只作参考，必须逐小节对照原图核对每个音，输出该页 `.bars` | 滚动队列，最多 3 个同时进行，一个结束立即开始下一个 |
| 2 自动检查 | `bars-to-score` 检查小节时值；`omr-assist.py audit` 列出检测到但转写中没有的音头 | 本机 |
| 3 独立复核 | 每页一个新复核者：原图 + 识读结果（不给程序草稿）+ 自动检查列出的疑点；必须逐小节对照原图检查全部音，不只看疑点；输出复核后的 `.bars` 与修改清单 | 滚动队列，识读完成一页就开始复核该页 |
| 4 合并 | 合并三页；若仍有时值错误，对出错小节各重读一次（最多 1 次） | 本机 + 按需 |

重复小节：程序只给出候选（检查谱号起止、调号、8va、音名与临时记号作用域、空心/附点/符尾和像素相似度；延音线、休止、跨页上下文检测不到）。识读者只能在对照原图确认完全相同、且被复制的小节在同一任务内时写 `N = M`，否则逐音识读。

输出：
- `runs/optimized/work/`：检测结果、重复候选、识读任务（草稿与裁图）
- `runs/optimized/readers/page-N.bars`：识读者输出（阶段 1）
- `runs/optimized/reviewed/page-N.bars`、`page-N.changes.md`：复核输出（阶段 3）
- `runs/optimized/transcription.bars`：最终原始输出（无人工修正）

评分分别报告阶段 1（仅识读）与阶段 3（复核后），二者都未经人工修正。
