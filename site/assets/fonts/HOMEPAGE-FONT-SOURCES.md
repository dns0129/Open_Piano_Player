# Homepage display font

`QinbanBrush-home.woff2` is a local, character-subset derivative of **Ma Shan Zheng Regular**.

- Original project: https://github.com/googlefonts/mashanzheng
- Distribution source: https://github.com/google/fonts/tree/main/ofl/mashanzheng
- Original font: https://raw.githubusercontent.com/google/fonts/main/ofl/mashanzheng/MaShanZheng-Regular.ttf
- Copyright: Copyright 2018 The Ma Shan Zheng Project Authors.
- License: SIL Open Font License 1.1. The complete, unchanged license and copyright notice are included in `MaShanZheng-OFL.txt`.
- Changes: subset to the homepage's Chinese copy and printable ASCII, convert to WOFF2 with FontTools, rename the derivative family to **Qinban Brush**. The subset remains under SIL OFL 1.1.
- Bundle: 389 mapped characters, 127,068 bytes. `QinbanBrush-home.charset.txt` lists the exact character coverage. Every character used by the homepage's brush-font selectors is present.
- Used for the expressive headline phrase, brand lettering, section headings and handwritten margin notes. Body text and interactive controls use the system Chinese sans-serif stack. Musical engraving continues to use the existing, separately licensed Bravura font.

The font is served from this repository. No visitor request to a third-party font service is needed.
