# 读谱与校对

## 提示词版本与升降号专项规则

沿用琴伴的 `accidentals-v2-20261018`。与节奏、音符效果的结构输出要求共同使用；不要替换掉当前谱号、调号和页/行上下文。

升降记号专项规则：
先读当前谱表的谱号、调号与音头线间位置，确定纸面音名字母和八度，再结合调号及临时记号计算实际音高；不要直接按黑键位置猜MIDI。书写音名与实际音高分开处理：降B与升A虽然等音，不能因此把原图的降号读成升号；原图若写降号，应保留该音名字母与降号的书写含义。
辨认♯、♭、♮、重升及重降时，检查记号完整轮廓和它的纵向中心；不要把谱线、符杆、附点或相邻和弦的笔画当成记号。密集和弦的记号可向左错位排列，必须按纵向音高将每个记号绑定到正确音头，不能仅按横向最近距离，也不能把一个记号套给整个和弦。
为每个谱表维护逐小节临时升降状态：以调号为默认值，显式临时记号覆盖同谱表、同音名字母、同八度在本小节后续的音；跨声部时核对同谱表关系，上下谱表与不同八度不擅自共用。跨小节恢复调号默认，除非原谱重新标记或有真正的跨小节延音。还原号使该音恢复自然音，不是恢复调号；之后再次出现升号或降号时更新状态。换谱号重新核对线间音高，不能沿用旧谱号的位置解释。
连奏弧与延音必须区分。真正跨小节延音的后续音头保持被延续的实际音高，但不能把这次延续当成新小节所有同名音的临时记号。提示性、括号中的记号按原图读取，不能让重复提示造成二次升降。
提交前对带显式记号、受调号影响及沿用临时记号的音逐项核查：原图音名字母/八度、有效升降值、实际MIDI是否一致；特别核查降号与还原号、和弦中相邻二度音程以及同小节后续未重写记号的音。只能根据原图纠正，不按和声习惯、曲名、前一次答案或记忆补写。仍无法确定时明确提示不确定或请求清晰谱面，不编造。

## 节奏与记号专项读取

音高首遍可输出暂时未知时值的工作表，但不提交到播放器。读音时必须保留空间坐标/声部的对应关系，不能把同一竖线上的多声部所有音都强行变为一个和弦。最后统一生成以四分音符为单位的时间轴。

- 扫描全部谱表的拍号、弱起、休止、附点、符尾/连梁、连音数字与括号。三连音不能靠缩短最后一个音凑小节；保持整个分组的比例。跨小节音用真正的延音链，不补发音。
- 速度读取“音符单位 + 附点 + 数值”，附点四分94应换算为四分141；不要直接把印刷94当全局四分BPM。变速记录实际位置，不根据歌曲音频猜。没有印刷速度时可用明确标为练习默认值的速度，报告不是原谱速度。
- 逐音绑定 >、^、断奏点、保持横线；横线可能是加线或音梁，要核对所在位置。p/f是动态而不是音高；动态通常作用于后续一段，沿用到变化处时要在播放数据逐音体现，勿只改一个音。
- 波音 mordent、颤音 trill、回音 turn、纵向琶音波浪线是不同符号。上/下波音的辅助音方向必须按图确定；装饰音辅助音受临时记号影响时显式读取半音间隔。倚音独立保存为零时值书写音，不能误当一个足拍主音。
- 延音线要求同音并延续发声；连奏弧可以跨不同音，不能合并为一个声响；延长记号(fermata)只说明停留，不代表固定增加一拍。踏板线是另一个层次的演奏控制，不等于音符duration。
- 扫描跨页/跨行连线、反复段落、第一第二房子、D.C./D.S./Coda。当前 helper 不实现的结构符号放 unhandled，保留原始证据，不因可播放而忽略。

可按系统行给模型提供原图裁切，但为换谱号/跨行延音等保留相邻区域；不只截音头而丢失谱线、记号和谱号。第一次成功后滚动处理剩余行，只重读失败或有分歧的区域；每次结果按输入页/行ID提交，不能靠完成顺序拼接。

## 复核与停止条件

1. 原图清单覆盖全部页/行，纸面末小节、首尾音和两手都存在；全页空白与封面有可核实理由。
2. 由音名字母/八度/有效alter复算MIDI；尤其核查临时降号、还原号和调号影响的音。小节内状态按谱表/音名/八度独立维护。算术一致不证明最初看图正确。
3. 逐声部核对节奏与休止，不以所有音符时值简单求和校验多声部；对齐的是时间区间和小节总长度。
4. 独立首读/复读都不能得到对方结果或参考答案。先冻结两份原始输出、再比较并记录逐项裁决和原图位置。按原图定夺，不能因多数一致删除疑点。
5. `checked`只表示已做指定方式的复核；没有人工确认时 humanConfirmed=false。模糊图、反复超时或缺页无法解决时保留局部结果和阻塞清单，不能制造“完整识别”。

## 评分与耗时口径

用户要求准确率时，需要未参与调参的独立参考（人工逐音标注或可靠授权的原始数字谱），在评分前冻结；记录来源、版本、全页覆盖及谁做了裁决。参考、上一轮识别答案和标准MIDI不能进入读谱提示词。只有模型自评时准确率为未知。

以小节、谱表、声部和音符事件对齐，单独保存错误表，至少给出以下分子/分母：

- **音高正确率** = 正确匹配音高数 / 已匹配参考音数，同时报告该匹配覆盖率；为了避免漏音使比例虚高，另给正确音高数 / 全部参考音数。
- **漏音率** = 未匹配参考音数 / 参考音总数。**多音率** = 未匹配预测音数 / 参考音总数。
- **升降号正确率** = 原谱显式记号读对数 / 原谱显式记号总数，另给受调号与沿用临时记号影响的实际音高正确率。等音不同写法（Bb/A#）在发声音高和书写识别分开计分。
- **节奏正确率** = 音高、起拍及符值均正确的匹配音数 / 参考音总数；起拍容差与连音/延音的等价规则必须预先写清，不能评完再改。
- **完全正确小节率** = 无错音、漏音、多音、节奏与要求记号错误的小节数 / 总小节数。无参考的页不能混入该分母装作正确。

左右手、首轮原始输出与人工校对后结果分开给表。前后优化比较固定模型、思考档位、原图字节/裁切策略、整曲范围、缓存策略、评分脚本和参考；若任何一项不同，标为不可直接归因。

总墙钟时间从开始该曲输入准备到全部页面识别、重试、校对、转换完成；另列识别与本地渲染用时，多曲并发的总墙钟时间不等于各曲时间之和。记录真实 startedAt/endedAt 和重试数；没有计时证据写未知。

Token 按每次调用的真实 usage 累计，首读/复读/重试都在内。保留输入、输出、缓存读/写、思考字段的供应商原始定义、缺失数量和记录覆盖率。input可能已含cached、output可能已含reasoning；不能重复相加。没有usage的调用不能用上下文估算、字符数、订阅额度百分比或计费金额替代。
