## 原文件与转换范围

- 每个子目录保留未修改的原 MIDI、原 PDF，以及原始 LilyPond 文件或完整源代码 ZIP；文件 SHA-256 均记录在清单中。
- 《月光》练习条目仅含第一乐章。原 MIDI ZIP、完整奏鸣曲 PDF 和源代码 ZIP 一并保留；`original.mid` 是原 ZIP 内 `moonlight1.mid` 的逐字节副本，未改编。
- 其余奏鸣曲条目也是标题所示单独乐章，不冒充完整奏鸣曲。《致爱丽丝》为完整曲目的原 MIDI 版。WoO 82 包含小步舞曲与三声中部，按源 MIDI 顺序播放，不额外补写 D.C. 回归。
- 数字谱从 MIDI 演奏事件生成；音高、拍位、时值和力度保持，按原谱核对音轨的上/下谱表映射、调式和弱起，保留 MIDI 中的拍号与调号变化。
- 音名、声部、休止和延音音头仍属于推断表示。指法、连奏线、踏板、细致表情和原页位置以 PDF 为准；重排谱面不是原版影印。反复按原 MIDI 的展开顺序。

## 离线重建

在仓库根目录执行 `node scripts/import-beginner-scores.mjs --manifest score-repo/intermediate-sources.json`，添加 `--local` 可接入本机磁盘曲库。已有同 ID 本地曲目保留；不会覆盖用户编辑。
