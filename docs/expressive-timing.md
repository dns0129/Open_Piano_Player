# 倚音、延长记号与变速

纸面 `beat` / `duration` 始终是四分音符拍数，保持原谱小节、休止与跟谱坐标。演奏由 `performanceNotes` 展开倚音与已有音符效果，再通过 `createScoreTimeline` 换算秒数。旧版 version 1 乐谱无需迁移，没有新字段时仍按固定速度播放。

## 数据约定

- `note.grace = { placement: 'before' | 'on', slash: boolean, stealBeats: number, notes: [{midi, velocity?}] }`：依附主音的有序倚音组，`slash` 保留有无斜线。`before` 借用同手、同声部的拍前空间；开头空间不足时回退到 `on`。`on` 占主音开头，最多占主音一半。借时只发生在演奏副本，不改写纸面主音及休止。对侧手不移拍。
- `note.fermata = {holdBeats}`：在音符纸面结束点额外停留，双手共享同一时钟。`score.fermatas = [{beat,holdBeats}]` 同时支持休止延长和谱行拼接后的全局标记。相同拍位取最长停留，避免双谱表重复加时。
- `score.tempoMap = [{beat,bpm,curve:'step'|'linear'}]`：`step` 保持到下一点，然后突然变速；`linear` 从本点的 BPM 线性变化到下一点，需要明确终点。首点不在 0 时以 `score.tempo` 开始。BPM 为四分音符速度。

倚音借时、延长记号的额外拍数和未定量渐变的终点属于可编辑演奏设置，不能宣称是谱面唯一解释。识别提示词要求对估计给出说明；短倚音默认每音 1/16 拍，未定量延长默认额外 1 拍。

## 演奏时间

固定速度一段耗时 `Δt = 60 Δbeat / BPM`。线性 BPM `B(b)=B0+k(b-b0)` 的时间为 `60 ln(B(b)/B0)/k`；斜率为零时退回固定速度公式。延长记号额外耗时为 `holdBeats × 60 / BPM(beat)`。延长期间书写拍位不动，音频时钟、进度秒数继续前进。

`createScoreTimeline` 同时提供 `secondsAt(beat, side)`、`beatAt(seconds)`、`tempoAt(beat)` 和总时长。默认边界取延长后的时间，`side='before'` 可取延长前时间。点击跳转到停留边界时从停留后的下一事件开始；暂停/继续、换音色、调练习速度则保留停留中的精确位置。练习 BPM 是相对于起始速度的比例，整条变速曲线和停留随之缩放。循环保留循环末尾的延长，节拍器按变速时间轴运行，停留期间不继续打拍。

## 端到端保留

整行识别协议 `compact-v3`：`graces` 仍引用原始音头下标；`graceStyles` 保留位置、斜线与借时；`tempos` 使用 `[beat,bpm,0或1]`；`fermatas` 使用 `[beat,holdBeats]`。解码把零时值倚音绑定到主音，结构校验继续按纸面时值执行。新提示词 `expressive-timing-v3-20261019` 使旧识别缓存失效，不恢复第二轮 AI 复核。历史乐谱已丢失的记号不能自动补回，需重新识别或手动填写。

跨行与跨页拼接给显式时间事件增加行偏移，保留全休止行的速度与停留。相邻行起始速度覆盖同边界上一行的结束速度；仅上下文 BPM 不会自动产生一次变速。

编辑入口：“编辑与改编”中的倚音/延长设置，以及“变速与休止延长”表格；支持撤销、重做和保存修改版。JSON 完整保留新字段。MusicXML 导出原生倚音、音符延长和速度方向，同时以琴伴扩展保留精确渐变、借时与额外停留；重新导入时恢复精确设置。外部 MusicXML 没有量化停留时采用 1 拍默认值；MIDI 导入保留全部数值速度事件。

MIDI 使用标准速度事件；延长展开为额外时间，倚音展开为演奏音符。渐变通常分成 1/32 拍的阶梯（超长乐谱自适应降低采样密度，总量最多 32768 个速度事件），每段使用精确积分的平均 BPM；受 MIDI tick 与微秒速度精度限制。MIDI 重新导入保留演奏结果，不能从音符事件反推原谱倚音或延长符号。MusicXML 在第三方软件中对琴伴扩展的支持取决于该软件。

可直接导入 `examples/expressive-timing.score.json`：两音倚音 → 渐慢 → 双手停留 → 恢复原速 → 拍前长倚音 → 结尾延长。
