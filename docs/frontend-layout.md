# 前端容器与滚动边界

各页面沿用原有配色和字体。布局遵循以下约定，新增面板时不再依赖提高 z-index 解决遮挡。

- `layout-foundation.css` 只提供容器可收缩、长文本换行、表单宽度上限和组件层叠边界；页面网格、尺寸与滚动由对应组件定义。
- 练习室的主区规则限定在 `.app-shell > main`。顶栏、工具栏、谱面、播放控制、键盘分别占位；专注模式仍为播放控制和退出按钮保留独立底栏。
- 弹窗由 `.modal-heading` 和 `.modal-body` 两个同级区域组成。标题与关闭按钮固定占位，正文独立滚动。宽度通过 `--dialog-width` 定义，实际尺寸始终受遮罩内边距约束。
- 识别校对样式独立在 `full-score-import.css`。审核工具栏正常占位，原谱、音符表格与音高网格在各自容器内滚动；窄容器通过 container query 改为单列。
- 搜索建议在搜索框下方占位，长曲名和操作按钮不挤进相邻榜单或侧栏。
- 账号页只加载账号及商业版基础样式，不引入练习室的页面高度与滚动规则。商业版处理状态在正文中占位。
- 弹窗遮罩、手机设置抽屉、谱内音符标记是有明确交互目的的覆盖层，区别于普通面板间的非预期重叠。

## 触摸与谱面大小

- `layout-foundation.css` 对所有页面关闭双击缩放和点按延迟（`touch-action: manipulation`），按钮、标签不可选中；触屏设备上表单字号不小于 16px，避免 iOS 聚焦输入框时自动放大页面。
- 练习室（`.app-shell.has-practice`）只保留单指平移：文字和谱面字形不可选中（VexFlow 把音符画成 `<text>`，长按会被当成选字），双指不缩放整页。`#notation` 上的双指捏合由 `notation.js` 接管，改为调整谱面大小。
- `renderNotation` 的 `overflow: "scroll"` 仅用于练习室：`zoom` 决定每行排几小节；一行即使只放一个小节仍超宽时，最多缩到 80%（`MIN_FIT`），再宽就保持大小、该行横向滚动，播放光标自动带着横向跟随。预览、编辑器与打印沿用默认的 `"fit"`，始终缩到容器宽度。
- 手动滑动、滚轮或翻页后，自动跟随暂停数秒，不与读谱的人抢滚动；重新排版（旋转屏幕、改大小）以可视区第一行所在小节为锚点恢复位置。
- 谱行进入视口前的排版每帧最多绘制一行，快速滑动时不会因为多行同时排版而卡顿。
- 手机上乐谱标题区只留一行拍号、调号与来源标记，曲名在工具条里；「读谱提示」默认折叠。

## 验证入口

```sh
node scripts/prepare-layout-check.mjs
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 8802 --strictPort
```

打开 `http://127.0.0.1:8802/.local/frontend-layout-check/matrix.html`。页面使用真实组件和样式、模拟账号与识别结果，按 320×640、390×844、844×390、1024×768、1440×900 检查练习室、识别校对、账号、商业版曲库与上传页共 25 个组合。检查器 `tests/helpers/frontend-layout-audit.mjs` 读取实际 DOM 几何，报告面板相交、内容横向越界和被锁住的长页面。

交互复测：识别弹窗滚动并展开重试／音符明细；搜索页输入“月光”展开曲名建议；练习室切换专注模式；打开编辑与打印弹窗。正常滚动容器内部的宽表格、琴键和乐谱不会被当成页面溢出。

本次识别弹窗滚动复现中，审核栏与工作区的重叠面积由约 95,780 px² 降为 0。自动 DOM 测试另覆盖弹窗替换／关闭、原练习 DOM 保留，以及已有审核、拖拽、撤销与保存行为。浏览器尺寸模拟不等同于物理手机验收。
