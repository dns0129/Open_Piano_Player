# App 实际模型接入 Skill 1.3.3

本次接入覆盖本机 App 的 Pi/GPT 首轮识别、独立数字复读、DeepSeek 共用的提交工具契约，以及商业版的报价/读取/解码路径。模型仍由现有策略固定为 GPT-6.1 Sol / high；不通过更换模型实现升级，也不重启已删除的定时任务。

## 接入内容

- `submit_score_region` 的模型可见 schema 增加可选逐小节 `meters`、`notation.clefs[].order`。拍号分母限定1/2/4/8/16，接收端继续核对meters与bars的长度及首拍号一致性。
- 实际 system prompt 明确 Skill 1.3.3 的纸面来源规则：显式变拍才列meters；同拍谱号必须有来源明确的先后；不能缩短声部范围来掩盖遗漏；非活动不等于休止；跨小节延音不伪造显式升降号；播放借时不改变倚音纸面时值。
- 本机、独立复读、商业版共享 `compactRegionInstructions` 与 `decodeCompactRegion`，避免模型看到的字段与保存/导出规则不同。
- 更新prompt/wire/cache版本；旧结果与旧缓存文件保留，新的缓存键不会把旧模型输出当成新契约结果。
- 本次是将项目Skill规则接到App模型输入，不覆盖用户目录已安装的独立Skill副本。

## 验证与发布

公开自动化测试在真实调用入口截获模型收到的系统消息及工具schema（使用假模型响应、不计真实调用），同时验证3/4→4/4和F→G有序谱号能够完整返回App结果。商业版验证报价与真正读取使用同一套规则。

模型输入发生变化，不能沿用上轮离线证据。本次沿用既有42案例/原参考范围：先运行9组冻结重放，再对原固定16条PDF谱行执行真实首读，每行最多1次、总预算16次，固定gpt-6.1-sol/high，无自动补救、无全曲重跑。来源原图、参考答案、范围和独立评分器保持不变；参考答案不发给模型。发布门禁必须验证真实调用凭据、当前实现/提示词指纹和固定范围覆盖，不能用修改门禁代替验证。

验证原件、响应及usage只保存在 `.local/app-skill133-20261031`，不提交原谱或凭据。部署到云端App与本机/源代码同步是不同状态，只报告实际验证的范围。
