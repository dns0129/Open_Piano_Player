# 整页对照修改

在练习页点“编辑与改编乐谱”，或在完整 PDF 识别结果里点“整页左右对照修改”，即可打开占满浏览器窗口的工作台。左侧是可编辑数字谱，右侧是对应原页；顶部按页翻动，页内所有谱行一起显示。两侧可缩放、各自滚动，也可同步滚动。

选中左侧的一个音符，拖动到五线谱的线／间与拍点。半透明音头和十字参考线显示实际落点；松开才修改，Esc 或移到无效位置松开会取消。同声部中不相容的节奏位置不接受落点，移入休止会同时调整新旧位置的休止。不同谱行之间保持各自的时间范围。原谱谱线已确认时，也可以从左侧拖到右侧原谱的相应线间与节奏格。

“单音试听”播放当前所选音符，选中音符后也可按 Enter 或空格。“播放当前页”按顺序播放该页所有谱行，保存连续音与延音；修改、翻页或关闭会停止试听。撤销与重做覆盖音符及原图定位。需要修改升降号、声部、和弦、调式或表达记号时，使用“精细参数与改编”，返回对照后继续编辑。

曲库乐谱的首次保存另存为“修改版”，原版本保留；再次编辑修改版时保存到同一版本。修改后的版本保留原谱及对应关系。识别草稿直接保留已应用的修改，返回后仍需审核，可继续使用“一键审核全部”。修改过的谱行会取消已审核状态。

新导入记录会保存完整原页及谱行图片。旧记录若只有谱行裁片，右侧会标注“保留谱行组成的整页视图”；从未保留原图的乐谱会明确提示原谱不可用。无法确认原谱谱线时，仍可在左侧固定音符格内修改，右侧保持对照显示。
