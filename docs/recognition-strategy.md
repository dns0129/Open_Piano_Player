# 升降号增强识谱策略

当前提示词版本为 `accidentals-v2-20261018`，原文位于 `lib/recognition-prompts.mjs`。单图、整谱谱行和独立复读共用这份规则；请求固定为 `gpt-6.1-sol` / `high`，不回退到本机 OMR。

先以谱号和音头线间位置确定音名字母、八度，再按调号和临时记号计算 MIDI。逐谱表、逐小节维护临时记号状态，区分降号、还原号、重升降、跨小节延音及和弦中错位排列的记号。更换提示词会使旧版识别缓存失效；文件版本并不构成准确率保证。

五首原谱的入口是 `npm run scores:reread-five`。默认只检查原始 PDF、全部 30 页和 143 行图片，不调用模型。加 `--run` 后新建或恢复本批任务：先让首行实际识读和复读成功，再继续整批。只复用本轮已完成的检查点，不把历史版本的音符答案交给模型。

运行器默认 16 路滚动请求，可用 `--concurrency` 调整，最大 100。超时或取消的请求在真实退出前仍占用物理并发槽，避免旧请求尚未结束就发出替代请求。

五本谱先共同进入滚动队列，某一本的慢行不会阻塞其余书目的发起。对没有提交工具结果或输出格式不合法的 Pi 请求，通用任务流程只额外尝试一次同模型、同思考强度的数字 JSON 输出；逐行结构检查和独立复读依然适用。该输出保留音高、节奏、声部和延音，缺少原谱音头坐标时不补造坐标，导入后使用重绘数字谱跟随；原图用于对照。

本轮补读仅使用本轮新识读的候选结果做独立一致性核查，拒绝模型、档位或提示词不符的结果。相同请求的副本不计第二票，最高票并列或只有一次有效读取时继续保留分歧。独立一致性只能发现部分错误，不能替代逐音真值或人工核对。

速度上下文与音符读取分开。后续谱行不重复印速度时，沿用本轮首页新识读的速度；原图明确的新速度和音符单位优先。没有数字标速时用明确标注的可编辑练习默认速度，不因缺少速度而拒绝读取音符，也不把先前练习设置当作原谱速度。

模型原始回答、调用时间、实际请求模型/思考档位、提示词版本、用量和续跑凭据保存在私有 `.local/batch-five-high-accidentals-v2/`。输出中的缺行、结构失败和独立复读分歧必须可见。导入不等于人工逐音确认；没有独立真值时不能自报全谱准确率。

`--import` 需要整批完整返回并通过结构及复读检查，写入曲库时保留旧版并标注 AI 待校对状态。`--publish` 再推送曲库。凭据、私有任务状态、用量原始日志和原始谱图不进入 Git。
